# E-commerce Data Analysis — Olist

Projeto de análise de dados desenvolvido a partir do Brazilian E-Commerce Public Dataset by Olist.

## Objetivo

Analisar dados de um marketplace brasileiro com o objetivo de identificar padrões de vendas, comportamento dos clientes, desempenho de vendedores, logística e oportunidades de melhoria para o negócio.

## Tecnologias

- Python
- Pandas
- PostgreSQL
- SQL
- Power BI
- Git e GitHub

## Etapas do projeto

1. Entendimento dos dados
2. Análise exploratória
3. Limpeza e tratamento
4. Modelagem do banco de dados
5. Análises utilizando SQL
6. Desenvolvimento de indicadores
7. Criação de dashboard no Power BI
8. Geração de insights e recomendações

## Dataset

Brazilian E-Commerce Public Dataset by Olist.
